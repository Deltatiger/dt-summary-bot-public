1. Who this policy covers

DT Summary Bot is a personal, non-commercial, self-hosted application maintained by an individual developer. It is not a public service, does not offer user accounts, and is operated for a single Gmail account whose owner has installed and authorised it.

This policy describes how the app handles data belonging to that account owner. If you are not the operator or the account owner, the app does not collect or process your information.

2. Information the app accesses

After the account owner grants consent through Google's OAuth 2.0 flow, the app can access the Gmail account using the scope https://www.googleapis.com/auth/gmail.modify. This scope permits reading messages and changing labels, including marking messages as read.

In practice, the app accesses only:

  • Matching email messages — unread messages from a short, owner-defined list of sender addresses. The app reads the sender, recipient, subject, date, message headers, body text, and images embedded in those messages.
  • Message identifiers and labels — used to fetch a message, avoid duplicates, and mark it as read after processing.
  • OAuth credentials — an access token and refresh token issued by Google, stored locally by the operator as described below.

The app does not request access to contacts, calendars, Drive, or any other Google service, and it does not read messages from senders outside the configured allow-list. It never sends, deletes, archives, or forwards email.

3. How information is used

Accessed information is used solely to operate the app's core function:

  1. Retrieve unread messages that match the configured senders.
  2. Parse the message and generate a concise summary, including describing embedded images where relevant.
  3. Post the summary to a private Discord channel chosen by the account owner.
  4. Mark the original message as read so it is not processed again.

Information is not used for advertising, profiling, analytics, marketing, or any purpose unrelated to producing and delivering these summaries.

4. Google API Services and Limited Use

Limited Use

DT Summary Bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Accordingly, Google user data is used only to provide the summarisation feature described in this policy. It is not sold, not transferred to third parties for advertising, and not used to develop, improve, or train generalised artificial intelligence or machine learning models. Access is limited to the minimum scope needed to perform the task.

5. Sharing and third parties

The app does not sell, rent, or trade personal information. Data is disclosed only to the service providers required to deliver the feature:

Recipient What is sent Purpose
AI model providers (e.g. Google Gemini, OpenRouter) Content of the matched email, including text and embedded images Generating the summary
Discord The finished summary Delivering it to the owner's private channel
Google OAuth requests for Gmail access Authentication and Gmail API operations

These providers process data under their own privacy policies. The account owner chooses which providers are configured. No data is shared with advertisers, data brokers, or other third parties. Data may also be disclosed where required by law.

6. Storage and retention

The app runs on a machine controlled by the operator. It has no central database or cloud account of its own. Data is stored as follows:

  • OAuth tokens — stored locally in a credentials token file so the app can reconnect without repeated sign-in. Tokens remain valid until revoked or deleted.
  • Configuration — the list of allowed senders, the Discord webhook URL, and provider API keys, stored in local configuration files.
  • Logs — operational logs may record timestamps, message identifiers, sender addresses, subject lines, and errors. Logs are kept only as long as needed for troubleshooting and are periodically cleared.
  • Delivered summaries — summaries exist in the owner's Discord channel and are subject to the owner's Discord retention settings.

Email content is not retained in a persistent store beyond the processing run. It is held in memory only while the summary is generated and delivered.

7. Security

Reasonable measures are used to protect credentials and data, including restricting access to the host machine, keeping API keys and token files out of public version control, and using encrypted HTTPS connections for all API calls. No method of transmission or storage is completely secure, so absolute security cannot be guaranteed.

8. Access, deletion, and revocation

The account owner can control and remove access at any time:

  • Revoke Google access — visit Google Account permissions and remove DT Summary Bot. Access stops immediately.
  • Delete local data — remove the token file, configuration files, and logs from the host machine, and delete delivered summaries from Discord.
  • Request information — contact the operator at the address below to ask what data is held or to request its deletion.

Deleting data locally does not affect copies held by third-party providers; those are governed by the providers' own policies and retention settings.

9. Children's privacy

The app is not directed to children under 13 and does not knowingly collect information from them. It is intended solely for the adult account owner who operates it.

10. Changes to this policy

This policy may be updated to reflect changes to the app or applicable requirements. The effective date at the top of this page will be revised, and material changes will be noted on this page. Continued use of the app after an update constitutes acceptance of the revised policy.

11. Contact
